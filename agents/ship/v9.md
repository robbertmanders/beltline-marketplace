Open a pull request for the work committed on the worktree branch {branch}. Do not change the code or make new commits.

1. Push {branch} to origin.
2. Snapshots: the build's output is {evidence} or {complex_build}, whichever exists. If its `## Snapshots` section lists PNG files that exist, upload each to the `beltline-assets` branch of this repository, never to {branch}. Otherwise skip this step.
   - Find the repository with `gh repo view --json nameWithOwner --jq .nameWithOwner`. If it has no `beltline-assets` branch (`gh api repos/<owner>/<repo>/branches/beltline-assets` fails), create it as an orphan branch that holds only snapshots, not from {base}:
     ```sh
     tree=$(gh api repos/<owner>/<repo>/git/trees -f 'tree[][path]=README.md' -f 'tree[][mode]=100644' -f 'tree[][type]=blob' -f 'tree[][content]=Snapshots for Beltline pull requests.' --jq .sha)
     commit=$(gh api repos/<owner>/<repo>/git/commits -f message="Start beltline-assets" -f tree="$tree" --jq .sha)
     gh api repos/<owner>/<repo>/git/refs -f ref=refs/heads/beltline-assets -f sha="$commit"
     ```
     If creating the ref fails because it now exists, another run made it first; carry on.
   - Upload each file to `snapshots/{branch}/<short head commit>-<file name>` with the contents API. Send the request body on stdin so large images fit: `jq -n --arg m "Snapshot for {branch}" --arg b beltline-assets --rawfile c <(base64 -i <file> | tr -d '\n') '{message: $m, branch: $b, content: $c}' | gh api -X PUT repos/<owner>/<repo>/contents/<path> --input -`.
   - A failed upload doesn't fail the stage: leave that snapshot out and note it in the body.
3. If a pull request from {branch} is already open, keep it and don't open another. Otherwise open one into {base} with `gh pr create --base {base} --head {branch}`.
   - Title: for a Jira ticket, its key, a colon, and its title; otherwise the title of what this run works on.
   - Body: first `Closes #<number>` for a GitHub issue, or a link to the Jira ticket. Then a short summary of the change, from the spec at {spec} and the build's output where they exist. Then, if you uploaded snapshots, a `## Snapshots` section with each as `![<what it shows>](https://github.com/<owner>/<repo>/blob/beltline-assets/<path>?raw=true)` and its description under it. End with the line "Opened by Beltline."
   - If the pull request was already open and its body has no `## Snapshots` section, add the uploaded snapshots to it with `gh pr edit`.

Write {pull-request}: the pull request's number and link.
