Open a pull request for the work committed on the worktree branch {branch}. Do not change the code or make new commits.

1. Push {branch} to origin.
2. If a pull request from {branch} is already open, keep it and don't open another. Otherwise open one into {base} with `gh pr create --base {base} --head {branch}`.
   - Title: for a Jira ticket, its key, a colon, and its title; otherwise the title of what this run works on.
   - Body: first `Closes #<number>` for a GitHub issue, or a link to the Jira ticket. Then a short summary of the change, from the spec at {spec} and the evidence at {evidence} where they exist. End with the line "Opened by Beltline."

Write {pull-request}: the pull request's number and link.
